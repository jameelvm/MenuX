## 4. Proposed MVP-1 scope

Doc 12 §8 applies, with Rev 0.3 decisions:
- **MVP-1:** tenant registration + multiple locations (outlets = locations) · roles and permissions (BFF login, MFA for Owner/Admin) · food catalog, variants, modifiers, allergens (canonical codes + market-pack scheme), optional halal/pork/alcohol fields, multilingual content (default + up to 4; Arabic + English with RTL end to end) · menus, sections, placements, per-menu price overrides, schedules (weekly + date-range overrides), price-display policy, sold-out flag via publish, locking · media uploads (WebP) · publishing (publish, rollback, unpublish) · QR codes (128-bit, PNG/SVG; PDF is flex) · static public menu · tenant export and deletion · static plan limits · first AWS environment with CI/CD, observability, restore drills.
- **Phase 2:** **AI menu import + Claude API integration (first phase-2 candidate)**, real-time sold-out overlay, AI translation, SaaS billing, analytics, branding/custom domains, location pricing, approval workflow, support console, automatic QR IP blocking, multi-account production. **Gates (draft):** LeadingKeys policies (T1) before any real pilot tenant; external pen test before the UAE commercial launch; pilot preparation and the pilot itself run after week 12 (doc 10 §12.5).
- **Future:** ordering, online payments, order board, integrations, organization hierarchy, retail inventory, customer accounts, customer-facing AI.

Flex scope and the protected tests: doc 10 §12.2–§12.3.
